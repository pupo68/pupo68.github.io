Inteligência Artificial & Agentes

Pipefy MCP Enterprise

⚠️ Desafio: Conectar agentes de IA (Google Gemini Enterprise e Antigravity) diretamente a fluxos de trabalho e tabelas corporativas do Pipefy com segurança, terminação TLS e sem expor credenciais.

🛠️ Solução: Construção de servidor corporativo baseado na especificação Model Context Protocol (MCP) sobre Starlette/Uvicorn. Implementação de curadoria inteligente de ferramentas, transporte StreamableHTTP e empacotamento em Docker com deploy no Cloud Run.

🚀 Impacto: Permite que agentes realizem ações transacionais completas (criação de cards, consultas estruturadas) em produção com latência mínima e arquitetura de custo zero.

  • Suporte dual: modo --stdio para IDE local e StreamableHTTP para nuvem
  • Deploy automatizado no Google Cloud Run com Docker
  • Curadoria de ferramentas para compliance com limites de context window
